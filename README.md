# Hi, I'm Viraj

I like building AI that has to be right, not just impressive. I'm a recent B.Tech (AI) graduate from Nagpur, with a six-month fintech data internship behind me and a paper published in IEEE Xplore.

## What I'm working on

**Agentic RAG Portfolio:** a LangGraph agent that picks between document search, a calculator, and a read-only SQL tool, or refuses when a question is out of scope. It comes with a 40-question evaluation set (35/40 on the first run), a written failure analysis, and notes on why that score may be overstated. I'm fixing two failure types now and re-measuring.
[github.com/VirajBarapatre/Agentic-RAG-Portfolio](https://github.com/VirajBarapatre/Agentic-RAG-Portfolio)

## Things I've built

- **[Ask My Portfolio](https://virajs-ask-my-portfolio.streamlit.app):** a live RAG chatbot that answers questions about my work, and only from the documents it's given.
- **AML-Sentinel-AI:** spots unusual transactions with an Isolation Forest, with backtested alert thresholds to cut false positives.
- **Dynamic Pricing Simulator:** forecasts demand, revenue, and profit across 20+ product categories (validation RMSE 13.36), deployed on Render.
- **CampusEYE:** attendance from video, a four-person team project that became a [published paper](https://ieeexplore.ieee.org/document/11724117). I built the frontend and tested the models.

## Ask me about

RAG and keeping answers grounded, evaluating AI systems, data validation and ETL, SQL, Power BI dashboards, and anomaly detection.
